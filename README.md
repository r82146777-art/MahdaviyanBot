# ربات مهدویان (MahdaviyanBot)

ربات روبیکا برای ارسال خودکار محتوای مذهبی **مهدوی** به کانال [Mahdaviyan_azari](https://rubika.ir/Mahdaviyan_azari).

## برنامه زمانی
- **هر ۳۰ دقیقه یک محتوا** از ساعت **۵:۰۰ صبح تا ۲۳:۰۰** به وقت تهران
- **بسته صبحگاهی ساعت ۵**:
  1. تقویم روز (شمسی + میلادی) + مناسبت + ذکر اعمال دینی
  2. یک متن مهدوی
  3. یک صفحه از قرآن کریم (ترتیبی از ۱ تا ۶۰۴ — بدون تکرار)
- بقیه روز: ارسال **ترتیبی و بدون تکرار** از:
  - متن‌های مهدوی
  - حکمت‌های نهج‌البلاغه
  - احادیث
  - خطبه‌های نهج‌البلاغه
  - نامه‌های نهج‌البلاغه
  - گاهی آیه قرآن

## بدون تکرار تا یک سال
سیستم ایندکس ترتیبی دارد. هر دسته (حکمت، خطبه، نامه، حدیث، مهدوی) را یکی‌یکی و بدون پرش جلو می‌برد. تا وقتی همه آیتم‌های یک دسته تموم نشده، هیچ تکراری از آن دسته ارسال نمی‌شود. قرآن هم صفحه به صفحه کامل می‌شود.

## فایل‌های اصلی
| فایل | نقش |
|------|-----|
| `post_once.py` | ارسال هر ۳۰ دقیقه (ترتیبی بدون تکرار) |
| `daily_morning.py` | بسته صبحگاهی ۵ صبح |
| `contents.py` | بانک متن‌های مهدوی |
| `nahj_content.py` | حکمت‌ها + خطبه‌ها + نامه‌ها + احادیث |
| `state.json` | ایندکس‌های ترتیبی و وضعیت |
