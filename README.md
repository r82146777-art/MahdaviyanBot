# ربات مهدویان (MahdaviyanBot)

ربات روبیکا برای ارسال خودکار محتوای مذهبی **مهدوی** (درباره امام زمان عج، ظهور، انتظار و ...) به کانال [Mahdaviyan_azari](https://rubika.ir/Mahdaviyan_azari) هر ۳۰ دقیقه یک‌بار.

## ویژگی‌ها
- ارسال متن‌های متنوع و غیرتکراری درباره امام مهدی (عج)
- آماده برای اضافه کردن عکس، ویدیو و صوت در آینده
- ساده و سبک (فقط با `requests`)

## پیش‌نیازها
1. ربات `@MahdaviyanBot` باید **ادمین** کانال باشد (با دسترسی ارسال پیام).
2. توکن ربات را داشته باشید.
3. `chat_id` کانال را پیدا کنید (معمولاً با `c0` شروع می‌شود).

### چطور chat_id کانال را پیدا کنیم؟
- ربات را ادمین کانال کنید.
- یک پیام تست در کانال بفرستید یا از کانال به ربات فوروارد کنید.
- با متد `getUpdates` آپدیت‌ها را بگیرید و `chat_id` را کپی کنید.
- یا در کد از یوزرنیم `@Mahdaviyan_azari` استفاده کنید (اگر کتابخانه پشتیبانی کند).

## نصب و اجرا

### روش ۱: اجرای محلی (کامپیوتر خودتان)
```bash
git clone https://github.com/r82146777-art/MahdaviyanBot.git
cd MahdaviyanBot
pip install -r requirements.txt
```

فایل `.env` بسازید:
```
BOT_TOKEN=توکن_ربات_شما
CHAT_ID=c0xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx   # یا @Mahdaviyan_azari
```

سپس اجرا کنید:
```bash
python bot.py
```

ربات هر ۳۰ دقیقه یک محتوا ارسال می‌کند و تا وقتی برنامه باز باشد کار می‌کند.

### روش ۲: بدون سرور با GitHub Actions (پیشنهادی برای شما)
1. به Settings > Secrets and variables > Actions بروید.
2. دو Secret اضافه کنید:
   - `BOT_TOKEN` = توکن ربات
   - `CHAT_ID` = شناسه کانال (c0...)
3. Workflow از قبل آماده است و هر ۳۰ دقیقه اجرا می‌شود.

> توجه: در پلن رایگان گیت‌هاب محدودیت دقیقه‌ای وجود دارد. اگر زیاد بود می‌توانید فاصله را به ۱ ساعت تغییر دهید.

### روش ۳: سرویس‌های رایگان
می‌توانید کد را روی سرویس‌هایی مثل Railway، Render، Fly.io یا PythonAnywhere آپلود کنید و همیشه روشن نگه دارید.

## افزودن محتوا و مدیا
- لیست محتواها در فایل `contents.py` است. می‌توانید اضافه/حذف کنید.
- برای عکس/ویدیو بعداً می‌توانیم متد `sendFile` را اضافه کنیم.
