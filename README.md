# ربات مهدویان (MahdaviyanBot)

ربات روبیکا برای ارسال خودکار محتوای مذهبی **مهدوی** به کانال [Mahdaviyan_azari](https://rubika.ir/Mahdaviyan_azari).

## برنامه زمانی جدید (از سپتامبر ۲۰۲۶)
- **هر ۳۰ دقیقه یک محتوا** از ساعت **۵:۰۰ صبح تا ۲۳:۰۰** به وقت تهران
- **بسته صبحگاهی ویژه ساعت ۵ صبح**:
  1. تقویم روز (شمسی + میلادی) + مناسبت + ذکر اعمال دینی پیشنهادی
  2. یک متن مهدوی
  3. یک صفحه کامل از قرآن کریم (عربی + ترجمه فولادوند) — هر روز صفحه بعدی
- بقیه ساعات روز: مخلوط متن مهدوی + حکمت‌ها، خطبه‌ها و نامه‌های نهج‌البلاغه + احادیث
- در انتهای هر پست لینک کانال قرار می‌گیرد

## ویژگی‌ها
- سیستم ضدتکرار قوی (تا ۱۲۰ پست اخیر)
- پوشش محتوا برای بیش از یک سال بدون تکرار سریع
- صفحه قرآن به ترتیب از ۱ تا ۶۰۴ و بازگشت
- اجرای رایگان با GitHub Actions

## پیش‌نیازها
1. ربات باید **ادمین** کانال باشد (با دسترسی ارسال پیام).
2. دو Secret در GitHub تنظیم شده باشد:
   - `BOT_TOKEN`
   - `CHAT_ID`

## فایل‌های اصلی
| فایل | نقش |
|------|-----|
| `post_once.py` | ارسال هر ۳۰ دقیقه (محتوای مخلوط) |
| `daily_morning.py` | بسته صبحگاهی ۵ صبح (تقویم + مهدوی + قرآن) |
| `contents.py` | بانک متن‌های مهدوی |
| `nahj_content.py` | نهج‌البلاغه + احادیث |
| `state.json` | وضعیت ضدتکرار و شماره صفحه قرآن |

## Workflowها
- `post.yml` → هر ۳۰ دقیقه (cron: `0,30 * * * *`) — فقط در بازه ۵–۲۳ تهران پست می‌فرستد
- `daily_morning.yml` → هر روز ساعت ۵ صبح تهران (cron: `30 1 * * *`)

## افزودن محتوا
- متن مهدوی جدید را به `contents.py` اضافه کنید.
- حکمت/خطبه/نامه/حدیث جدید را به `nahj_content.py` اضافه کنید.

## توکن امنیتی
**هرگز توکن را در کد قرار ندهید.** فقط از Secrets استفاده کنید.
